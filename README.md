# VPR_2026

Progetto relativo a Visual Place Recognition (VPR) per il corso/anno 2026.

## 📦 Clonare la repository

Per scaricare il progetto in locale:

```bash
git clone https://github.com/pietrovalese/VPR_2026.git
cd VPR_2026
```

## 📦 Clonare con submodules (se presenti)

Se utilizzi submodule, usa:

```bash
git clone --recurse-submodules https://github.com/pietrovalese/VPR_2026.git
```

Oppure, se hai già clonato la repo:

```bash
git submodule update --init --recursive
```

## 🛠️ Struttura del progetto

* `data/` → dataset (se presenti)
